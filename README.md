# Hainan Medical University BSC Rehab Study Files

海南医学院康复治疗学（中外合作办学）本科阶段学习资料汇总。  
这个仓库用于系统整理四年本科期间积累的课程资料、复习材料、实验报告、英方课程文件与实习信息，也希望能给后续同学提供一个更容易检索和使用的资料入口。

## 项目定位

- 面向对象：海南医学院康复治疗学（BSC Rehab）相关同学
- 资料范围：课程课件、复习笔记、题库图片、实验报告、作业范例、实习信息
- 使用目标：帮助快速定位历年资料，减少重复整理成本

## 资料类型说明

仓库内资料以以下格式为主：

- `pdf`：复习资料、课堂讲义、论文、实验报告
- `doc` / `docx` / `rtf`：作业草稿、整理笔记、单词解释、文档型资料
- `pptx`：课程课件、展示文稿
- `jpg` / `png`：题库截图、手写笔记、资料拍照件
- `xmind`：少量思维导图类资料

## 使用建议

- 优先查看课程目录中的 `pdf` 和整理文档，通常更适合作为复习主线
- 题库截图更适合配合课程资料使用，不建议脱离知识点单独刷图
- 对于英方课程，建议把课件、作业范例和总结资料结合起来看
- 如果你是第一次使用 GitHub，可以直接在网页端进入文件夹逐层浏览

## 使用须知

1. 本仓库仅供学习交流与个人整理参考使用
2. 请不要直接抄袭作业、实验报告或课程材料
3. 仓库中如有未完全脱敏的信息、版权问题或不适合公开的内容，请及时联系处理
4. 如果某些资料存在版本差异，请以老师当学期最新要求为准

## 贡献与维护

欢迎补充后续资料，但建议尽量遵守以下约定：

- 优先按 `年级 / 学期 / 课程 / 资料` 的结构存放
- 文件名尽量写清课程名、用途和版本，方便搜索
- 尽量避免上传系统缓存文件或 Office 临时文件
- 较大的课件或压缩包建议先确认是否真的有必要纳入仓库
- 上传前建议先参考 [隐私脱敏指南](./隐私脱敏指南.md)
