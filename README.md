# 🏥 海南医学院 (HNMU) 康复治疗学本科学习资料库

欢迎来到我的本科资料开源项目！这也是我做的第一个Github项目，这里记录了我大学四年在康复治疗学（BSC Rehab）专业期间的学习足迹、实验报告以及心得分享。

## 🌟 建立初衷
建立这个仓库是为了系统梳理我本科期间的资料，并为海医西英学院的学弟学妹提供参考，希望能帮助大家在专业学习和备考过程中少走弯路。

## 📂 资料分类说明
本资料库将严格按照本科四年的阶段进行分目录整理，你可以根据自己所在的年级快速查找对应资料：

* **Year 1 (大一)**：主要是英语学习，同时应该进行比赛规划。
* **Year 2 (大二)**：专业基础课。
* **Year 3 (大三)**：康复专业核心课程与大量英方课程。
* **Year 4 (大四)**：临床实习笔记、毕业设计（论文）相关及升学准备。
